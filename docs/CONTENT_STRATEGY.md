# Saeid KING Content Strategy

## Objective

Position Saeid KING as a serious Arabic-language media channel with a clean, sponsor-ready web presence.

## Audience

The site should serve new viewers, returning YouTube subscribers, sponsors, and possible collaborators.

## Brand promise

Saeid KING explains complex events with calm structure, visual storytelling, and careful wording.

## Editorial pillars

1. Global analysis.
2. Economy and technology.
3. Visual storytelling.
4. Clear summaries for YouTube and mobile viewers.

## Guardrails

1. Separate facts from analysis and assumptions.
2. Avoid fake urgency and inflated claims.
3. Use real YouTube links only after verification.
4. Use audience numbers only when copied from YouTube Studio.
5. Keep personal administration and legal matters outside the public media brand.

## Website roadmap

Phase 1 adds the static homepage, contact path, robots file, and Codex guidance.

Phase 2 should add a verified YouTube channel link, selected videos, a real media kit page, privacy page, 404 page, sitemap, and a stronger visual identity.

Phase 3 can add English sponsor copy, a video archive, and a downloadable media kit after the numbers are verified.

## KPIs

1. The channel positioning is clear within five seconds.
2. The mobile experience is clean.
3. The contact path is visible.
4. No unverified claims are published.
5. The repository stays safe for public GitHub Pages deployment.
