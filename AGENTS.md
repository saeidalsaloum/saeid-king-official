# Repository instructions

This repository contains the static official website for **Saeid KING**.

## Brand and safety

- Use the brand spelling exactly: `Saeid KING`.
- Use the public contact email exactly: `saeidkingofficial@gmail.com`.
- Do not add phone numbers, private personal data, legal case material, or personal administration material.
- Do not add tracking, analytics, cookies, forms, external scripts, third-party embeds, remote fonts, or new dependencies.
- Do not invent sponsors, testimonials, press mentions, audience numbers, video links, achievements, or unverifiable claims.

## Site structure

- Keep Arabic public pages Arabic-first with `lang="ar"` and `dir="rtl"`.
- Keep `en.html` English with `lang="en"` and `dir="ltr"`.
- Keep all public pages referencing `assets/css/styles.css` and local assets only.
- Keep the site GitHub Pages-ready from the repository root.
