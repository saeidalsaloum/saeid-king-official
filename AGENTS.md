# AGENTS.md

This repository is the public website for the Saeid KING YouTube channel.

Codex work rules:

1. Keep the site static and GitHub Pages friendly.
2. Use Arabic-first RTL layout.
3. Do not add phone numbers, legal case material, family details, banking details, or official authority files.
4. Do not add fake video links, fake sponsor logos, fake testimonials, or unverifiable audience numbers.
5. Do not add external scripts, trackers, forms, cookies, or analytics without a separate review.
6. Keep copy serious, calm, and sponsor-ready.
7. Prefer small pull requests with clear summaries and manual test notes.

Review checklist:

1. The site works on mobile.
2. Arabic text direction is correct.
3. Contact uses email only.
4. No confidential material is exposed.
5. No exaggerated claims are introduced.
6. GitHub Pages can deploy from the repository root.
